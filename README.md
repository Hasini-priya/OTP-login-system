# 🔐 Advanced OTP Login System (Python)

A console-based **Advanced OTP Login System** built using Python. This project simulates a real-world authentication process by validating user credentials and verifying a randomly generated one-time password (OTP) with added security features.

---

## 🚀 Key Features

* 🔑 **Multiple User Authentication** (simulated database using dictionary)
* 👁️ **Flexible Password Input** (user can choose visible or hidden password)
* 🔐 **Secure Login Attempts Limit** (account locks after multiple failures)
* 📲 **Random 4-digit OTP Generation**
* ⏳ **OTP Expiry System** (valid for limited time)
* 🔄 **Resend OTP Option**
* 🚫 **Limited OTP Attempts** for security
* 📁 **Login Activity Logging** (stored in a file)

---

## 🧠 Concepts Used

* Conditional Statements (`if-else`)
* Loops (`while`)
* Data Structures (Dictionary for user storage)
* String Handling
* Random Number Generation (`random`)
* Time Handling (`time` for OTP expiry)
* Secure Input (`getpass`)
* File Handling (logging system)

---

## 🎯 Project Purpose

This project demonstrates how authentication systems work in real-world applications, including:

* User credential validation
* OTP-based verification
* Security mechanisms like expiry, retries, and account locking
* Basic logging for tracking user activity
